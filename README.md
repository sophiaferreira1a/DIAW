# DIAW - Desenvolvimento e Integração de Aplicações Web

Este repositório reúne os projetos desenvolvidos durante a disciplina Desenvolvimento e Integração de Aplicações Web do 2º período do curso de Engenharia de Software da PUC Minas.

👥 Professor regente: João Paulo Aramuni [https://github.com/joaopauloaramuni]


## Projetos

### 1. API de Clima
📌 API REST desenvolvida em Java com Spring Boot para consultar informações meteorológicas de uma cidade, utilizando a API pública Open-Meteo (Geocoding + Forecast). Projeto desenvolvido como atividade acadêmica, com foco em consumo de APIs externas, arquitetura REST e organização em camadas.

**Tecnologias**
- Java
- Spring Boot
- Spring WebFlux (WebClient)
- Jackson
- Open-Meteo Geocoding API
- Open-Meteo Forecast API 

🔗 Repositório: [https://github.com/sophiaferreira1a/ClimaAPI]
🎯 Link da atividade: [https://github.com/joaopauloaramuni/desenvolvimento-e-integracao-de-aplicacoes-web/blob/main/ATIVIDADES/ATIVIDADE%2001.md]


### 2. AcessoPUC
📌 Aplicação em Java com Spring Boot que simula o fluxo de login, cadastro e recuperação de senha do sistema da PUC Minas, com base no projeto de referência SecureLoginPUC_3. Inclui uma API REST para administração de usuários e recuperação de senha por e-mail real via Spring Mail, com geração de token temporário e perfil de teste local para simular envios sem usar credenciais reais.

**Tecnologias**

- Java
- Spring Boot
- Spring Security
- Spring Mail (JavaMailSender)
- Thymeleaf
- Maven

🔗 Repositório: [https://github.com/sophiaferreira1a/AcessoPUC]
🎯 Link da atividade: [https://github.com/joaopauloaramuni/desenvolvimento-e-integracao-de-aplicacoes-web/blob/main/ATIVIDADES/ATIVIDADE%2002.md]
