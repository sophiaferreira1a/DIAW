Este repositório reúne os projetos desenvolvidos durante a disciplina Desenvolvimento e Integração de Aplicações Web do 2º período do curso de Engenharia de Software da PUC Minas.

## Projetos

### 2. API de Clima
📌 API REST desenvolvida em Java com Spring Boot para consultar informações meteorológicas de uma cidade, utilizando a API pública Open-Meteo (Geocoding + Forecast). Projeto desenvolvido como atividade acadêmica, com foco em consumo de APIs externas, arquitetura REST e organização em camadas.

**Tecnologias**
- Java
- Spring Boot
- Spring WebFlux (WebClient)
- Jackson
- Open-Meteo Geocoding API
- Open-Meteo Forecast API 

🔗 Repositório: https://github.com/sophiaferreira1a/ClimaAPI
